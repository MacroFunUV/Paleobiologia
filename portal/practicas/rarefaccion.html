Práctica 1. Del registro fósil a la curva de rarefacción

Descargar el código y los datos (ZIP)

Construiremos una comparación de dos listas de géneros desde cero. Empezaremos por abrir los archivos en R, comprobar qué representa cada fila y distinguir cuántos registros tenemos de cuántos géneros contienen. Después haremos un sorteo, lo repetiremos y dibujaremos las curvas. Al final podremos explicar qué aporta cada gráfico y qué información necesitaríamos para convertir el ejercicio en un análisis de investigación.

El código usa R base. RStudio puede utilizarse para ejecutarlo por tramos y ver los resultados en la consola. Los recursos introductorios incluyen la guía de instalación de R y RStudio, el curso de R de la Universitat de València y el tutorial de la Paleobiology Database.

Vídeo de introducción a Paleobiology Database.

1. Abrir los datos y comprobar qué contienen

Los archivos 750–550 Ma y 200–0 Ma proceden de una descarga de la Paleobiology Database atribuida a Europa. Cada fila contiene un nombre de género. El mismo nombre puede aparecer en muchas filas. Trabajaremos con registros de estas listas, que es la unidad que podemos contar directamente.

Descomprime el material de la práctica y abre el archivo de R en RStudio. En el menú de la sesión, fija la carpeta de trabajo en la carpeta descomprimida. Para ejecutar una línea, coloca el cursor sobre ella y pulsa Ctrl + Intro. Ejecuta los pasos en orden, porque cada uno utiliza objetos creados en los anteriores. Las líneas que empiezan por # son comentarios. El símbolo <- guarda el resultado con el nombre que aparece a la izquierda.

# Comprueba la carpeta de trabajo y que R ve los dos CSV.
getwd()
list.files()

# Los archivos no tienen cabecera. [[1]] extrae la primera columna.
tabla_antigua <- read.csv("genus-europe-750-550.csv", header = FALSE)
tabla_reciente <- read.csv("genus-europe-200-0.csv", header = FALSE)

# Quita espacios sobrantes al principio y al final de cada nombre.
antiguo <- trimws(tabla_antigua[[1]])
reciente <- trimws(tabla_reciente[[1]])

# Muestra los primeros registros y comprueba si hay nombres vacíos.
head(antiguo)
head(reciente)
stopifnot(!anyNA(antiguo), all(nzchar(antiguo)))
stopifnot(!anyNA(reciente), all(nzchar(reciente)))

2. Contar registros, géneros y frecuencias

length() cuenta las entradas de una lista. unique() devuelve cada nombre una sola vez. Por eso, length(unique()) cuenta la riqueza de géneros observada. table() cuenta cuántas veces aparece cada nombre. Conservamos los nombres repetidos en los datos, porque su frecuencia afecta al resultado de los sorteos.

# Un recuento de filas y otro de nombres distintos para cada lista.
resumen <- data.frame(
  intervalo = c("750-550 Ma", "200-0 Ma"),
  registros = c(length(antiguo), length(reciente)),
  generos = c(length(unique(antiguo)), length(unique(reciente)))
)
print(resumen)

# Los seis géneros con más registros en la lista antigua.
frecuencias_antigua <- table(antiguo)
frecuencias_reciente <- table(reciente)
head(sort(frecuencias_antigua, decreasing = TRUE))

Deberías obtener 329 registros y 107 nombres distintos en la lista antigua, y 268 213 registros y 21 522 nombres distintos en la reciente. Los nombres se cuentan tal como figuran en los archivos, antes de una revisión taxonómica.

3. Sacar una submuestra de 250 registros

sample() elige registros al azar. Con replace = FALSE, cada fila puede entrar una sola vez en el sorteo, aunque varias filas pertenezcan al mismo género. set.seed() hace que podamos repetir el sorteo en las mismas condiciones. Cuenta primero las filas seleccionadas y después los géneros distintos que contienen.

set.seed(2026)
n <- 250
submuestra <- sample(antiguo, size = n, replace = FALSE)
length(submuestra)          # 250 registros seleccionados.
length(unique(submuestra))  # Géneros en este sorteo.

4. Repetir el sorteo y calcular la media

Un sorteo puede recuperar más o menos géneros que otro. replicate() repite el cálculo y guarda los resultados. La media de los sorteos aproxima la riqueza esperada para 250 registros. El mínimo y el máximo describen la variación entre estas 500 submuestras de la colección.

set.seed(2026)
riquezas <- replicate(500, {
  seleccion <- sample(antiguo, size = n, replace = FALSE)
  length(unique(seleccion))
})
mean(riquezas)
range(riquezas)

5. Calcular la curva y comparar a igual número de registros

Para construir la curva calcularemos la riqueza esperada directamente, como en el ejemplo de A, B y C. La función phyper() permite obtener, para cada género, la probabilidad de que salga al menos una vez al elegir registros sin reemplazo. Le damos el número de registros del género, el número de registros de todos los demás y el tamaño de la submuestra. Sumamos las probabilidades para obtener el número esperado de géneros.

# Esta función recibe la tabla de frecuencias y el tamaño de submuestra.
riqueza_esperada <- function(frecuencias, tamano) {
  frecuencia <- as.integer(frecuencias)
  total <- sum(frecuencia)

  # lower.tail = FALSE pide la probabilidad de superar cero.
  presencia <- phyper(0, m = frecuencia, n = total - frecuencia,
                      k = tamano, lower.tail = FALSE)
  sum(presencia)
}

# Comprueba el resultado exacto del ejemplo de cinco registros.
riqueza_esperada(table(c("A", "A", "B", "B", "C")), 2)

# Contrasta el promedio simulado con el resultado exacto.
riqueza_esperada(frecuencias_antigua, 250)
riqueza_esperada(frecuencias_reciente, 250)

# Un tamaño común puede llegar hasta el total de la lista más pequeña.
tamanos <- 0:min(length(antiguo), length(reciente))
curva_antigua <- vapply(tamanos, function(n) {
  riqueza_esperada(frecuencias_antigua, n)
}, numeric(1))
curva_reciente <- vapply(tamanos, function(n) {
  riqueza_esperada(frecuencias_reciente, n)
}, numeric(1))

# plot() abre el gráfico y lines() añade la segunda curva.
plot(tamanos, curva_antigua, type = "l", lwd = 2, col = "#17606b",
     ylim = range(c(curva_antigua, curva_reciente)),
     xlab = "Número de registros", ylab = "Géneros esperados")
lines(tamanos, curva_reciente, lwd = 2, lty = 2, col = "#9a4a26")
legend("topleft", c("750-550 Ma", "200-0 Ma"),
       col = c("#17606b", "#9a4a26"), lty = c(1, 2), lwd = 2, bty = "n")

A 250 registros esperamos unos 94 géneros en la lista antigua y 238 en la reciente. Cada curva responde a la misma pregunta para su lista. Al llegar a 329 registros usamos toda la colección antigua y solo una pequeña parte de la reciente.

6. Ampliación. Comparar la forma de las curvas

En este segundo gráfico cada lista conserva su propia escala. En el eje horizontal, el 100 % equivale a 329 registros en la lista antigua y a 268 213 en la reciente. En el eje vertical, dividimos la riqueza esperada por la riqueza observada de la lista correspondiente. Ambas curvas llegan a 1 al usar todos sus registros. Esta representación sirve para comparar qué fracción de los géneros ya registrados se recupera a lo largo de cada lista.

porcentajes <- 0:100

curva_relativa <- function(frecuencias) {
  tamanos <- round(sum(frecuencias) * porcentajes / 100)
  esperados <- vapply(tamanos, function(n) {
    riqueza_esperada(frecuencias, n)
  }, numeric(1))
  esperados / length(frecuencias)
}

plot(porcentajes, curva_relativa(frecuencias_antigua), type = "l",
     ylim = c(0, 1), lwd = 2, col = "#17606b",
     xlab = "Registros seleccionados (% de cada lista)",
     ylab = "Fracción esperada de los géneros de la lista")
lines(porcentajes, curva_relativa(frecuencias_reciente),
      lwd = 2, lty = 2, col = "#9a4a26")
legend("bottomright", c("750-550 Ma", "200-0 Ma"),
       col = c("#17606b", "#9a4a26"), lty = c(1, 2), lwd = 2, bty = "n")
